# Browsers

r[browsers.mobile-minutes]

Nothing a test runs starts a Multilogin cloud phone. A test may run a browser profile (GoLogin,
Multilogin's browser); a phone is billed per running minute and starts only from a person's action
in `serve`.

r[browsers.phone-stops]

A cloud phone that started stops on every path its run ends by, the stop confirmed by Multilogin; one
the runner may have started and did not see stop is stopped before it serves again.
